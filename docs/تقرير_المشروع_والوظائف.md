## أولاً: قائمة الوظائف المكتملة فعلياً في المشروع (Completed Features)

### 1. الواجهة والهوية والتصميم
- [x] واجهة عصرية متطورة تعتمد على React 18 و TypeScript و Tailwind CSS.
- [x] دعم كامل وتلقائي للغتين العربية والإنجليزية مع التبديل السلس لأعلام مصر 🇪🇬 والولايات المتحدة 🇺🇸.
- [x] دعم أصيل للاتجاهين RTL و LTR وتبديل اتجاه القوائم والنصوص بدون تشوه.
- [x] دعم الوضع الليلي الداكن (Dark Mode) والوضع النهاري الفاتح (Light Mode).
- [x] تجاوب كامل مع كافة أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة).
- [x] سلايدر رئيسي ديناميكي مع إمكانية تعديل البانرات وسرعة التبديل التلقائي.

### 2. دورة الشراء والطلبات (Purchase Lifecycle)
- [x] عرض المنتجات المصنفة مع الصور المتعددة والفيديو وسعر المقارنة والمخزون.
- [x] صفحة تفاصيل المنتج المنبثقة مع اختيار المقاس واللون والكمية.
- [x] سلة مشتريات تفاعلية منزلقة (Cart Drawer) مع التحكم بالكميات والتحديث اللحظي.
- [x] دورة شراء كاملة (اسم، هاتف مصري معتمد، محافظة من بين الـ 27 محافظة، عنوان مفصل، وملاحظات).
- [x] نظام حساب الشحن التلقائي (50 ج.م كافتراضي، ومجاني عند تجاوز 1000 ج.م).
- [x] نظام الكوبونات التفاعلي بنوعيه (نسبة مئوية ومبلغ ثابت) مع حدود الطلب الأدنى.
- [x] منع النقر المزدوج (Idempotency) وحماية الطلبات من التكرار عند ضعف الاتصال.
- [x] معالجة طلب الدفع عند الاستلام (COD) مع حق المعاينة والفحص للعميل قبل السداد.
- [x] نافذة تأكيد الطلب الفورية مع تأثيرات الاحتفال (Confetti).
- [x] توليد فاتورة شراء رقمية فورية معتمدة قابلة للطباعة والتحميل بصيغة PDF مع كود QR.
- [x] زر تأكيد فوري عبر واتساب المتجر (يرسل تفاصيل الطلب بالكامل لإدارة المتجر برابط مباشر).

### 3. قاعدة البيانات والأمان (Supabase Architecture)
- [x] ملف SQL شامل ومتكامل (`supabase/schema.sql`) ينشئ 11 جدولاً وفهارس مخصصة.
- [x] دالة إنشاء الطلب الذرية `create_cod_order` مع قفل الصفوف بالخادم (`FOR UPDATE`) لمنع سباق نفاذ المخزون.
- [x] سياسات حماية صارمة على مستوى الصفوف (Row Level Security - RLS).
- [x] منع العملاء من الاطلاع على طلبات الآخرين أو استعراض سجلات الإدارة.
- [x] منع ترفيع الصلاحيات الذاتي بواسطة Trigger خادمي يمنع تغيير الدور إلى Admin أو Owner.
- [x] مخزن Supabase Storage مهيأ لرفع صور المنتجات بروابط عامة للمشاهدة ورفع مقصور على المديرين.
- [x] النشر اللحظي (Realtime) للطلبات لإرسال إشعارات فورية للوحة الإدارة فور تسجيل أي طلب.
- [x] وضع العمل دون اتصال (Offline Fallback) يضمن عمل المتجر محلياً حتى قبل إدخال مفاتيح Supabase.

### 4. لوحة الإدارة والتحكم (Admin Control Suite)
- [x] قفل لوحة التحكم ببيانات الاعتماد وفحص الدور (Admin/Owner) في قاعدة البيانات.
- [x] شاشة إحصائيات تنفيذية (إجمالي المبيعات، الطلبات، الطلبات المعلقة، وتنبيهات انخفاض المخزون).
- [x] استقبال الطلبات اللحظية مع تنبيهات صوتية وشريط إشعار فوري عند وصول أوردر جديد.
- [x] تتبع الطلبات مع إمكانية تحديث الحالة (قيد الانتظار، جارٍ التجهيز، تم الشحن، تم التسليم، ملغي).
- [x] تحديث حالة الدفع للطلبات.
- [x] إدارة المنتجات الكاملة (إضافة، تعديل، حذف، تحديد الأسعار، الخصومات، والكميات).
- [x] رفع الصور مباشرة وتخزينها في Supabase Storage أو رفعها محلياً.
- [x] إدارة الأقسام والتصنيفات ديناميكياً مع تعديل المسميات باللغتين.
- [x] قسم متابعة العملاء (Customers Manager) الذي يحصي عملاء المتجر، إجمالي مشترياتهم، ويوفر رابط واتساب مباشر لكل عميل.
- [x] إدارة كوبونات الخصم (تفعيل، تعطيل، إضافة، وحذف).

- [x] إدارة وتدريب البوت الذكي على الكلمات المفتاحية للرد الآلي في المحادثة الحية.
- [x] تصدير سجل الطلبات والعملاء إلى ملفات CSV بضغطة زر واحدة.
- [x] مركز أمان لوحة الإدارة وإرشادات منح صلاحية المالك للمديرين الجدد.

### 5. نظام بوابات الدفع (Payment Adapters)

## ثانياً: قائمة الوظائف غير المكتملة بعد وأسبابها المنطقية

| الوظيفة | سبب عدم اكتمالها | الإجراء المطلوب من العميل للاستكمال |
| :--- | :--- | :--- |
| **تفعيل الدفع الإلكتروني المباشر (Paymob / Fawry / Kashier)** | لا يمكن تفعيل بوابات الدفع الإلكترونية الحقيقية بدون حساب تجاري رسمي ومفاتيح سرية ورمز تاجر معتمد من الشركة المزودة والبنك المركزي. تم توفير الأكواد ومحولات الربط ودوال Webhook في انتظار بياناتك. | توفير الـ API Key و HMAC Secret من حسابك في بوابة الدفع. |
| **توليد حزمة تطبيق iOS بصيغة (.ipa)** | يتطلب نظام التشغيل macOS حصرياً وبرنامج Xcode مع حساب مطور مدفوع لدى شركة Apple للتوقيع الرقمي، ولا يمكن قانونياً أو تقنياً توقيع تطبيق iOS داخل بيئات ويندوز. | فتح المشروع على جهاز Mac واتباع الخطوات في `دليل_تطبيق_الهاتف_Android_iOS.md`. |
| **إرسال رسائل SMS أو رسائل بريد SMTP حقيقية للعملاء** | يتطلب ذلك ربط بوابة رسائل SMS مدفوعة أو خدمة SMTP خارجية (مثل Resend أو Brevo). المتجر يوفر حالياً التأكيد الفوري عبر واتساب وهو الأكثر رواجاً ومجاني للعملاء في مصر. | إدخال بيانات SMTP في لوحة تحكم Supabase > Auth > SMTP Settings. |

## ثالثاً: قائمة الحسابات والمفاتيح التي تحتاج إلى توفيرها لتشغيل المتجر على الإنترنت

1. **حساب Supabase (مجاني - Free):**
   - الرابط: [https://supabase.com](https://supabase.com)
   - المتغيرات المطلوبة: `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.

2. **حساب Cloudflare (مجاني - Free):**
   - الرابط: [https://cloudflare.com](https://cloudflare.com)
   - للاستضافة السريعة المجانية وربط الدومين وتفعيل شهادة الحماية SSL.

3. **حساب GitHub (مجاني):**
   - لحفظ الكود والربط التلقائي مع Cloudflare Pages.

4. **حساب بوابة الدفع الإلكتروني (اختياري - عند الرغبة في كروت الفيزا والمحافظ):**
   - Paymob (Merchant ID, API Key, Integration ID, HMAC Secret)
   - أو Kashier (Merchant ID, Secret Key)
   - أو Fawry (Merchant Code, Security Key).
