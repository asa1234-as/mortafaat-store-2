# دليل تشغيل واستخدام متجر مرتفعات ستور | Mortafaat Store
## الدليل التشغيلي الشامل للمالك وفريق العمل

مرحباً بك في متجر **مرتفعات ستور (Mortafaat Store)**!  
تم تطوير وتأسيس هذا المتجر ليكون منصة تجارة إلكترونية تجارية متكاملة وعالية الأمان تعتمد على أحدث معايير الويب (React 18، TypeScript، Vite، Tailwind CSS، Supabase، Cloudflare Pages، PWA، و Capacitor).

---

## 1. التشغيل المحلي السريع (Local Development)

### الخيار أ: التشغيل التلقائي بضغطة زر واحدة (على Windows)
اضغط مرتين على ملف:
```text
تشغيل_المتجر.bat
```
سيقوم الملف تلقائياً بفتح المتجر على الرابط `http://localhost:3000` وتشغيل الخادم المحلي.

### الخيار ب: عبر سطر الأوامر (Terminal)
```bash
# 1. تثبيت الحزم (إن لم تكن مثبتة)
npm install

# 2. تشغيل جناح الاختبارات للتأكد من سلامة النظام
npm test

# 3. تشغيل سيرفر التطوير المحلي
npm run dev
```

---

## 2. كيفية تسجيل الدخول إلى لوحة إدارة المتجر (Admin Control Suite)

المتجر محمي بنظام أمان ثنائي:
1. **في وضع التطوير المحلي (قبل ربط Supabase):**
   - اضغط على أيقونة الدرع في أعلى الصفحة (`بوابة إدارة المتجر`).
   - اكتب البريد: `admin@mortafaat.com`
   - اكتب رمز المرور: `1234`
   - سيتم فتح لوحة الإدارة فوراً.

2. **بعد ربط قاعدة بيانات Supabase (وضع الإنتاج الحقيقي):**
   - سجل حسابك ببريدك الإلكتروني من واجهة المتجر.
   - قم بترقية حسابك إلى رتبة مالك من Supabase SQL Editor كالموضح في `docs/دليل_إعداد_Supabase.md`.
   - ادخل إلى لوحة الإدارة ببريدك وكلمة مرورك الموثقة في قاعدة البيانات.

---

## 3. اختبارات الجودة وفحص النظام

تم بناء جناح اختبارات آلي شامل للتأكد من سلامة كافة العمليات الحسابية ومنطق الأمان والمخزون:
```bash
npm test
```
للتحقق من سلامة بناء حزمة الإنتاج:
```bash
npm run build
```

---

## 4. فهرس أدلة المشروع المفصلة

للحصول على شرح تفصيلي لكل جانب من جوانب المشروع، يرجى مراجعة الأدلة التالية في مجلد `docs/`:

1. [دليل إعداد وربط قاعدة بيانات Supabase](docs/دليل_إعداد_Supabase.md)  
   *خطوات إنشاء المشروع المجاني، تشغيل ملف الـ SQL، وتفعيل المصادقة وتخزين الصور.*

2. [دليل الاستضافة والنشر على Cloudflare Pages](docs/دليل_نشر_Cloudflare.md)  
   *خطوات النشر المجاني السريع مع ربط الدومين وشهادة الأمان SSL وحساب GitHub.*

3. [دليل تطبيق الهاتف (PWA و Capacitor Android & iOS)](docs/دليل_تطبيق_الهاتف_Android_iOS.md)  
   *خطوات تثبيت PWA الفوري على الهواتف، وبناء تطبيق Android و iOS.*

4. [تقرير نتائج الاختبارات البرمجية والأمان](docs/نتائج_الاختبارات_الفعلية.md)  
   *سجل نتائج فحص الأكواد، البناء، منع التكرار، وحماية المفاتيح.*

5. [تقرير حالة المشروع وقائمة الحسابات المطلوبة](docs/تقرير_المشروع_والوظائف.md)  
   *بيان الوظائف المنجزة بالكامل، وما يلزم توفيره من بوابات الدفع.*

## 5. هيكل مجلدات المشروع

```text
mortafaat-store/
├── dist/                          # ملفات الواجهة الجاهزة للنشر والرفع
├── docs/                          # أدلة التشغيل والنشر وإعداد السيرفر بالعربية
├── public/
│   ├── _headers                   # ترويسات أمان Cloudflare Pages
│   ├── _redirects                 # توجيهات مسارات SPA لـ Cloudflare Pages
│   ├── manifest.json              # إعدادات تطبيق الويب التقدمي (PWA)
│   ├── sw.js                      # Service Worker للعمل أوفلاين
│   ├── icon-192.png               # أيقونة التطبيق للموبايل
│   └── icon-512.png               # أيقونة التطبيق عالية الدقة
├── src/
│   ├── components/                # مكونات الواجهة (لوحة الإدارة، السلة، الدفع، الفاتورة...)
│   ├── context/StoreContext.tsx   # إدارة حالة المتجر وتكامله اللحظي مع Supabase
│   ├── data/initialData.ts        # البيانات الافتراضية الأولية للمتجر
│   ├── lib/
│   │   ├── supabase.ts            # عميل REST والـ Auth وقاعدة البيانات لـ Supabase
│   │   └── paymentGateway.ts      # محول بوابات الدفع (COD, Paymob, Kashier, Fawry)
│   ├── types/index.ts             # تعريفات TypeScript لكافة عناصر المتجر
│   ├── i18n.ts                    # محرك الترجمة للغتين العربية والإنجليزية
│   ├── translations.en.ts         # قاموس الترجمة الإنجليزية
│   ├── App.tsx                    # المكون الرئيسي للواجهة
│   └── main.tsx                   # نقطة انطلاق التطبيق وتسجيل PWA
├── supabase/
│   ├── schema.sql                 # مخطط قاعدة البيانات وسياسات RLS والدوال الذرية
│   └── functions/
│       └── payment-webhook/       # كود Edge Function للتحقق من Webhooks المشفرة
├── tests/
│   └── ecommerce.test.mjs         # جناح الاختبارات الآلية المعتمد
├── .env.example                   # نموذج متغيرات البيئة بدون أسرار
├── capacitor.config.ts            # إعدادات تطبيق الهاتف Capacitor
└── package.json                   # حزم واعتماديات المشروع
```
