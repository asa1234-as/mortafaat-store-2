# 🏔️ مرتفعات ستور | Mortafaat Store
مشروع متجر إلكتروني تجاري متكامل ومحمي جاهز للتشغيل والتعديل والنشر.

---

## 🚀 كيفية تشغيل المتجر على جهازك:
1. **الطريقة السريعة:** اضغط مرتين على ملف:
   `تشغيل_المتجر.bat`
   وسيفتح المتجر تلقائياً في متصفحك على: `http://localhost:3000`

2. **عبر سطر الأوامر:**
   ```bash
   npm run dev
   ```

3. **تشغيل الاختبارات الآلية:**
   ```bash
   npm test
   ```
