# 🏔️ مرتفعات ستور | Mortafaat Store
مشروع متجر إلكتروني متكامل جاهز للتشغيل والتعديل.

---

## 🚀 كيفية تشغيل المتجر في أي وقت على جهازك:
1. **الطريقة السريعة:** اضغط مرتين (Double Click) على ملف:
   `تشغيل_المتجر.bat`
   وسيفتح المتجر تلقائياً في متصفحك على: `http://localhost:3000`

2. **عبر سطر الأوامر (Terminal / VS Code):**
   ```bash
   npm run dev
   ```

---

## 🛠️ كيف تعدل على كود المتجر وتكمل برمجته؟
* افتح المجلد في **Visual Studio Code** أو أي محرر كود.
* **الهيكل الرئيسي للملفات:**
  * `src/components/Header.tsx`: الهيدر، الشعار، الأعلام، البحث، وزر لوحة التحكم.
  * `src/components/HeroSlider.tsx`: سلايدر البانرات الإعلانية في أول الصفحة.
  * `src/components/ProductCard.tsx`: كارت عرض المنتج والأسعار والخصومات والتمرير.
  * `src/components/ProductDetailModal.tsx`: صفحة تفاصيل المنتج، الفيديو، والمراجعات.
  * `src/components/CheckoutModal.tsx`: صفحة الدفع وإتمام الطلب واختيار بوابات الدفع.
  * `src/components/InvoiceModal.tsx`: الفاتورة الفورية (نسخة أبيض وأسود مع QR Code).
  * `src/components/LiveChatWidget.tsx`: شات الزوار المتحرك بحرية بالماوس.
  * `src/components/AdminDashboard.tsx`: لوحة تحكم التاجر الشاملة (PIN الافتراضي: 1234).
  * `src/data/initialData.ts`: المنتجات والأقسام والإعدادات الافتراضية.
  * `src/context/StoreContext.tsx`: إدارة الحالة والبيانات وذاكرة التخزين (LocalStorage).
