# 🏔️ مرتفعات ستور | Mortafaat Store

المتجر الإلكتروني المتكامل وتطبيق الإدارة الشامل لعلامة **مرتفعات ستور (Mortafaat Store)**.
مبني بأحدث التقنيات السريعة بهوية فاخرة بألوان (الذهبي والأسود والأبيض) ومستوحى من تجربة تصفح منصات التسوق الكبرى مثل "More Shopping".

---

## ✨ المميزات الرئيسية للمتجر

### 1. المتجر للعملاء (Storefront):
- **الأقسام الخمسة الرئيسية:**
  - 📱 الإلكترونيات والذكاء
  - 👕 الملابس والأزياء الشتوية والصيفية
  - ✨ العطور الفاخرة (شموخ المرتفعات)
  - 🏠 الأدوات والأجهزة المنزلية
  - 💖 العناية والأدوات الشخصية
- **محرك بحث وتصفية ذكي:** بحث فوري بالاسم، الوصف، أو القسم مع فلترة المنتجات المتوفرة بالمخزون وترتيب الأسعار.
- **سلة مشتريات متطورة:** حساب مباشر للشحن المجاني مع شريط تقدم تفاعلي.
- **طرق الدفع المتعددة:**
  - الدفع عند الاستلام (Cash on Delivery) بعد معاينة وفحص المنتج.
  - محافظ إلكترونية (فودافون كاش، أورنج، اتصالات، وي) مع نسخ الرقم بنقرة واحدة.
  - إنستاباي / تحويل بنكي فوري (InstaPay).
- **طلب فوري عبر واتساب:** زر مباشر في كل منتج وسلة المشتريات لتأكيد الأوردر ومراسلته للواتساب فوراً.
- **شات دعم فني متصل:** ويدجت شات عائم للإجابة عن الأسئلة الشائعة مع تحويل سريع للواتساب.

### 2. تطبيق الإدارة ولوحة التحكم (Admin App / PWA):
- **إحصائيات حية:** إجمالي المبيعات، عدد الطلبات، الطلبات قيد المراجعة، وعدد المنتجات.
- **إدارة المنتجات:** إضافة منتج جديد مع رفع الصور من جهازك، تعديل الأسعار، الخصومات، والكمية المتوفرة بالمخزون، أو حذف أي منتج.
- **إدارة الطلبات:** متابعة وتغيير حالة الطلبات (قيد المراجعة ➔ جاري التجهيز ➔ تم الشحن ➔ تم التسليم)، مع بيانات العميل ورقم هاتفه وعنوانه بالتفصيل.
- **الربط مع أمازون ونون وجوميا:** تصدير شيت إكسيل/CSV بضغطة زر جاهز للرفع الجماعي (Bulk Upload) في:
  - Amazon Seller Central
  - Noon Partner
  - Jumia Vendor Hub
- **إعدادات المتجر الكاملة:** تعديل رقم فودافون كاش، معرف إنستاباي، رقم الواتساب، تكلفة الشحن، والبانر الإعلاني.
- **تثبيت كتطبيق (PWA):** يمكن تثبيته كأيقونة تطبيق على هاتفك الآيفون أو الأندرويد والكمبيوتر بدون متاجر تطبيقات.

## 🚀 كيفية تشغيل المتجر محلياً على جهازك

1. افتح التيرمينال داخل مجلد المشروع:
```bash
cd C:\Users\hp\.gemini\antigravity\scratch\mortafaat-store
```

2. شغل السيرفر المحلي:
```bash
npm run dev
```

3. افتح المتصفح على الرابط:
`http://localhost:3000`

## 🌐 كيفية نشر المتجر مجاناً 100% مدى الحياة على Vercel

1. أنشئ حساباً مجانياً على [Vercel.com](https://vercel.com) أو [Netlify.com](https://netlify.com).
2. اسحب مجلد `mortafaat-store` أو ارفعه على GitHub.
3. اضغط **Deploy**.
4. ستحصل فوراً على رابط متجرك المباشر مجاناً مدى الحياة مع شهادة أمان SSL تلقائية!
