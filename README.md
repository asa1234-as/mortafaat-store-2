# مرتفعات ستور | Mortafaat Store
### Production-Ready Commercial E-Commerce Storefront

منصة تجارة إلكترونية تجارية متكاملة وعالية الأمان تم بناؤها باستخدام React 18 و TypeScript و Tailwind CSS و Supabase و Cloudflare Pages و PWA و Capacitor.

---

## ⚡ المميزات الرئيسية (Key Highlights)
- **دعم كامل للغتين:** واجهة عربية أصيلة مع اتجاه RTL واجهة إنجليزية كاملة مع اتجاه LTR مع التبديل الفوري للأعلام.
- **الوضع الليلي والنهاري:** Dark Mode & Light Mode متكامل على طراز كبرى المتاجر.
- **دورة شراء كاملة:** سلة مشتريات ديناميكية، تحقق من أرقام الهواتف المصرية، عناوين التوصيل لـ 27 محافظة، نظام الكوبونات التفاعلي.
- **دفع آمن بالمعاينة (COD):** الدفع نقداً عند الاستلام مع حق الفحص والمعاينة قبل السداد كطريقة أساسية.
- **فواتير إلكترونية فورية:** طباعة وتحميل فواتير Sahl-Style PDF رقمية معتمدة مع كود QR.
- **تأكيد مباشر عبر واتساب:** زر واتساب ينقل بيانات الأوردر والمنتجات مباشرة لخدمة عملاء المتجر.
- **قاعدة بيانات Supabase Free:** دوال خادمية ذرية (`create_cod_order`) تتحقق من الأسعار والمخزون مع قفل الصفوف (`FOR UPDATE`).
- **حماية قصوى RLS:** سياسات أمان مشددة على مستوى الصفوف، ومنع ترقية الصلاحيات الذاتي.
- **لوحة إدارة متكاملة:** إدارة المنتجات، رفع الصور إلى Supabase Storage، إدارة الأقسام، مراقبة المخزون، استقبال الطلبات لحظياً مع إشعارات Realtime وتنبيهات صوتية، متابعة العملاء وسجل مشترياتهم، وتصدير ملفات CSV.
- **جاهز لتطبيق الهاتف (PWA & Capacitor):** ملف manifest متكامل، Service Worker للتخزين المؤقت، وإعداد Capacitor لـ Android و iOS.
- **استضافة مجانية:** مهيأ بالكامل لـ Cloudflare Pages و GitHub Actions CI/CD مع صفر تسريب للمفاتيح السرية.

---

## 🚀 البدء السريع (Quick Start)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل جناح الاختبارات الآلية
npm test

# 3. تشغيل وضع التطوير المحلي
npm run dev

# 4. بناء نسخة الإنتاج
npm run build
```
